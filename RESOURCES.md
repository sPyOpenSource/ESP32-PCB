# KiCad Resources

## Knowledge

- [KiCad Official Documentation](https://docs.kicad.org/)
  The authoritative manual for KiCad. Covers Eeschema (schematic), Pcbnew (board), footprint editor, symbol editor, Gerber output, and more. Use for: anything about how a KiCad feature works, file formats, or workflow steps.
- [KiCad User Forum](https://forum.kicad.info/)
  Community-maintained discussion board moderated by KiCad maintainers and experienced users. Use for: troubleshooting specific errors, library questions, workflow advice.
- [KiCad GitHub Repository](https://github.com/KiCad/kicad)
  Primary source for the KiCad codebase, release notes, and issue tracker. Use for: checking if a behavior is a bug, seeing what changed between versions.

## Wisdom (Communities)

- [r/KiCad](https://www.reddit.com/r/KiCad/)
  Active subreddit for KiCad users. Use for: project feedback, seeing what others are building, informal tips.
- [KiCad Discord](https://discord.gg/kicad)
  Real-time chat with KiCad developers and power users. Use for: quick questions, getting unstuck mid-project.

## Notes
- You are using KiCad 10 (generator_version "10.0" in your project files). Resource links target KiCad 10 / current stable where possible.
